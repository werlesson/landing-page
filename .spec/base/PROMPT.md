# Context

I already have a personal website that is fully implemented and live.

This is **NOT** a redesign from scratch.

This is an iterative redesign.

The goal is to preserve as much of the existing website as possible while repositioning my personal brand for international recruiters.

## Important

Before making any changes:

- Analyze the existing website.
- Preserve the current visual identity whenever possible.
- Reuse existing sections when they still make sense.
- Keep the current component structure whenever possible.
- Avoid unnecessary changes.
- Only replace sections that do not communicate seniority or fail to add value.

The objective is evolution, not reconstruction.

Think like a Staff Product Designer reviewing an existing product rather than creating a brand-new portfolio.

The current website is:

https://werlesson.vercel.app

# Design Philosophy

Every proposed change must be justified.

For each section, decide whether to:

✅ Keep as is

✏️ Improve

🔄 Replace

❌ Remove

If a section is already good enough, keep it.

Do not redesign components simply because they could look better visually.

Prioritize communication, credibility, and clarity over aesthetics.
