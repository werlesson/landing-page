## Stack

| Layer      | Technology                                  |
| ---------- | ------------------------------------------- |
| Framework  | Nuxt 4 (SSR)                                |
| UI         | Vue 3 + Composition API + TypeScript        |
| Styling    | Tailwind CSS 3 (no component library)       |
| i18n       | @nuxtjs/i18n — PT-BR (default) + EN-US      |
| SEO        | nuxt-schema-org · @nuxtjs/sitemap           |
| Utilities  | @vueuse/nuxt                                |
| Fonts      | Syne 700 (display) · DM Sans 400/500 (body) |
| Tests      | Vitest                                      |
| Linting    | @nuxt/eslint (flat config)                  |
| Formatting | Prettier                                    |

---

## Features

- **Hero** — typewriter effect cycling through 3 roles, animated counters, glitch on name, particle burst on CTA hover, mouse spotlight
- **About** — career timeline (2019 → 2025) with scroll-triggered animations and tech badges per milestone
- **Stack** — 24+ technologies grouped by Frontend, Backend, Data and Infrastructure
- **Project** — interactive mock of _Eu no Play_ with real-time clock, rolling buffer, capture animation and link to [eunoplay.com.br](https://www.eunoplay.com.br)
- **Contact** — form + direct social links (GitHub, LinkedIn, Email)
- **Fully bilingual** — all strings from locale JSON files, zero hardcoded text
- **SEO-ready** — Schema.org Person + WebSite, Open Graph, Twitter Card, sitemap

## Getting Started

**Prerequisites:** Node.js 20+ and yarn (or npm)

```bash
# 1. Clone
git clone https://github.com/werlesson/werlesson-cv.git
cd werlesson-cv

# 2. Install dependencies
yarn install

# 3. Start dev server
yarn dev
```

The site will be available at `http://localhost:3000`.

## Available Scripts

| Command              | Description                      |
| -------------------- | -------------------------------- |
| `yarn dev`           | Start development server         |
| `yarn build`         | Build for production             |
| `yarn preview`       | Preview production build locally |
| `yarn generate`      | Generate static site             |
| `yarn test`          | Run unit tests (Vitest)          |
| `yarn test:watch`    | Run tests in watch mode          |
| `yarn test:coverage` | Run tests with coverage report   |
| `yarn lint`          | Lint with ESLint                 |
| `yarn lint:fix`      | Lint and auto-fix                |
| `yarn format`        | Format with Prettier             |
| `yarn typecheck`     | TypeScript type checking         |

> **Note:** Run `yarn dev` (or `nuxt prepare`) at least once before running `yarn lint` — ESLint config is generated by the `@nuxt/eslint` module.

## Linting & Formatting

This project uses [`@nuxt/eslint`](https://eslint.nuxt.com) with flat config and Prettier for formatting.

```bash
# Lint
yarn lint

# Lint + auto-fix
yarn lint:fix

# Format all files
yarn format
```

`.prettierrc` enforces: no semicolons, single quotes, 100-char print width, LF line endings.

## Internationalization

All UI strings live in `locales/en.json` and `locales/pt.json`. Portuguese is the default locale (`/`), English is available at `/en/`.

To add a new locale:

1. Create `locales/xx.json` mirroring the existing structure
2. Add the locale to `nuxt.config.ts` → `i18n.locales`

## Deployment

The site is SSR-enabled and can be deployed to any Node.js host or as a static site.

**Vercel (recommended):**

```bash
npx vercel
```

**Static export:**

```bash
yarn generate
# Deploy the .output/public folder
```
